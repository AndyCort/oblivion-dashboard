# 下一步更新设计方案

## 页面定位

「未央」是以浏览和阅读为主的个人展示空间。Now 展示近况，Notes 展示想法，Library 展示书影音收藏；内容通过代码配置维护。已选定并实现 A 杂志式单屏布局：大标题、主文、侧栏精选摘要。Now、Notes、Library 在桌面和手机均占满当前视口，不出现页面内部滚动，超出容量时仅展示精选内容。

保留现有背景、衬线标题、留白、主题切换、全屏翻页和 Moments 内容滚动。右侧小点导航维持紧凑半透明胶囊，随指针活动显现；移动端不增加底部导航。音乐播放器默认收缩，音源在代码中配置。Home 和 Moments 的现有展示结构保留。

## 第一阶段：内容与阅读层次

| 页面 | 下一步内容 | 呈现方式 |
| --- | --- | --- |
| Now | 真实近况、阶段关注、正在进行的项目 | 一段主叙述与少量状态条目，更新日期由内容配置提供 |
| Notes | 更完整的原创笔记与主题系列 | 一篇精选配最多三条短摘要，手机精简为一条摘要 |
| Library | 真实书影音收藏、封面与短评 | 三本书封配短评和影乐摘要，手机只展示一本书与一项影乐 |

内容数据继续与布局分离，条目使用稳定 ID；封面和可选链接由代码配置。没有链接的卡片不显示箭头或按钮，不把装饰元素做成看似可点击的控件。日期与状态只使用真实配置值，不自动生成阅读经历、完成进度或更新记录。

验收：页面无需登录或录入即可阅读；所有卡片均有实质内容；窄屏内容不溢出；新增条目不需要修改组件布局；屏幕内所有选中的内容均完整可见。

## 第二阶段：访问与媒体体验

导航加入 URL 状态，使分享和刷新能够回到指定页面；确保浏览器前进、后退与页面状态一致。图片配置本地资源或可靠的公开地址，补齐替代文本、比例占位和加载失败处理，避免加载期间跳动。

音乐继续作为全局悬浮播放器。若后续配置多首曲目，再添加有实际内容的播放列表和前后切歌；收起和切页不中断播放。音源错误时保留曲目信息，给出清晰提示。

验收：分享链接能定位正确页面；浏览器历史可用；图片失败不影响阅读；未配置的链接和音源不会显示无效操作。

## 第三阶段：Moments 与内容维护

待展示页稳定后，单独评估 Moments 的标签筛选、分页、图片预览和服务异常提示。若文章数量增加，可将代码配置迁移为静态 Markdown 或公开内容接口；前台保持阅读界面，内容管理与展示分离。

## 视觉与质量约束

- 共用主题颜色与 PageLayout，维持桌面多列、移动端单列及清晰的文字层级。
- 初始内容与顶部栏保持间距；为底部状态与收缩播放器预留空间，主内容完整容纳在可用区域中。
- 装饰图标对屏幕阅读器隐藏；真实操作提供可访问名称和键盘焦点。
- 尊重减少动态效果设置；静态内容不引入额外定时器和本地存储。
- 验证 320×568、390×844、768×1024 和 1440×900，覆盖浅深主题、单屏内容边界、导航及播放器收起展开。

自动化检查集中在音源验证、接口数据处理及未来的路由行为；纯文案和排版通过生产构建、实际页面与移动端预览确认。
